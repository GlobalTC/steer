# How Steer works

Steer is a desk, not a writer. You mark. Save. The rewrite follows the marks. The human stays the authority.

This Learn page is a sandbox. Edits, marks, Save, and Ready stay in the browser. They do not write the catalog. They do not wake the save-ping.

## Viewing

Read the paper. You cannot type here. Use this when you are reviewing, not rewriting.

## Editing

The source. Raw markdown. Fix a word yourself when a mark would be overkill.

## Suggesting

Select a phrase, then Comment or Replace. That writes CriticMarkup into the source. Comments become the spec for the rewrite.

Practice on this slop:

In today's rapidly evolving landscape, we leverage synergy to drive impactful results.

Select “rapidly evolving landscape” and comment: *say what actually happened*.

## Save

On a real draft, Save writes the file and wakes Steer. Here, Save only pretends. Reload this page and the tutorial is back.

## Ready

Ready means the text is shippable. Publishing is a separate ask. Here, Ready is also pretend.
